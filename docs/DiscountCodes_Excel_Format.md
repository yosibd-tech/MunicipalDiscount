# מבנה קובצי האקסל — קודי הנחה ותעריפים

העברת קודי ההנחה מרשות אחת לאחרת נעשית בשני קובצי אקסל. שניהם יחד הם התמונה
המלאה: הקליטה **מוחקת** את הקודים הקיימים ברשות היעד ומחליפה אותם — אין מיזוג.

| קובץ | טבלה במסד | תוכן |
|------|-----------|------|
| `DiscountCodes.xlsx` | `tbDiscountsCodes` | שורה אחת לכל קוד הנחה — ההגדרה |
| `DiscountRates.xlsx` | `tbDiscountCodeRates` | שורה אחת לכל גרסת תעריף, עם תאריך תחילת תוקף |

הפרדה זו קיימת כי לקוד אין תעריף אחד: העירייה משנה אחוזים גם באמצע השנה, וכל
שינוי הוא שורה נוספת בקובץ התעריפים. התעריף שחל על תושב הוא הגרסה שהייתה בתוקף
בתאריך הבקשה שלו.

**באפליקציה:** מסך *קודי הנחה* → `ייצוא קודים ותעריפים לאקסל` ו-`קליטת קודים ותעריפים מאקסל`.

## איפה הקבצים יושבים

`C:\MunicipalDiscount\HelperFiles\DiscountCodes` — בסייר Windows מוצגת
בשם **"קודי הנחה ותעריפים"**.

תיקייה מנוהלת ככל תיקיות היבוא: הנתיב שמור ב-`tbMainParameters` תחת המפתח
`DiscountCodesPath` בקבוצה "סיפריות קבצים", והיא נוצרת אוטומטית בעליית האפליקציה
עם השם העברי. אפשר לשנות את הנתיב במסך הפרמטרים. שני הדיאלוגים — ייצוא וקליטה —
נפתחים שם.

התיקייה `Templates\` שבתוך קוד המקור אינה מקום לנתונים: היא שימשה למעבר החד-פעמי
מהמבנה הישן, ומה שיושב בה הוא היסטוריה של אותו מעבר.

## קובץ 1 — `DiscountCodes.xlsx`

גיליון ראשון, שורה 1 = כותרות, הנתונים מתחילים בשורה 2. סדר העמודות אינו חשוב —
הזיהוי הוא לפי שם הכותרת. עמודה שאינה מוכרת נעלמת בקליטה עם אזהרה.

| כותרת | עמודה במסד | סוג | חובה | הערות |
|-------|------------|-----|------|-------|
| `קוד עירוני` | MunicipalDiscountCode | מספר שלם | ⬥ | לפחות אחד מהשניים הראשונים |
| `קוד חוקי` | LegallDiscountCode | מספר שלם | ⬥ | 23 מהקודים הם חוקיים בלבד |
| `קטגוריה` | Categories | טקסט | | למשל "מבחן הכנסה", "בניין/נכס" |
| `קוד קבוצה` | GroupCode | מספר שלם | | |
| `שם הנחה` | DiscountName | טקסט | | השם מופיע כאן בלבד, לא בקובץ התעריפים |
| `חובה` | Mandatory | טקסט | | "חובה" / "רשות" |
| `חוק בתוקף` | LawInForce | טקסט | | |
| `מסמכים נדרשים` | Documents | טקסט | | |
| `הערה` | Remark | טקסט | | |
| `כללים` | Rules | טקסט | | |
| `תנאים` | Conditions | טקסט | | |

⬥ = חובה שאחד מהשניים יהיה מלא.

**כללים**

- הצמד `קוד עירוני` + `קוד חוקי` הוא המזהה של השורה, ולכן חייב להיות **ייחודי**.
  שורה כפולה עוצרת את הקליטה ומצביעה על מספרי השורות בקובץ.
- שורה שבה שני הקודים ריקים נדחית — אי אפשר לקשר אליה תושב.
- כל עמודות הטקסט מוגבלות ל-**255 תווים**.
- אין עמודת `ID` ואין עמודת `שנה`. המזהים נקבעים במסד היעד, ולקוד אין שנה.

## קובץ 2 — `DiscountRates.xlsx`

| כותרת | עמודה במסד | סוג | חובה | הערות |
|-------|------------|-----|------|-------|
| `קוד עירוני` | — | מספר שלם | ⬥ | הקישור לקובץ הקודים |
| `קוד חוקי` | — | מספר שלם | ⬥ | הקישור לקובץ הקודים |
| `תאריך תחילת תוקף` | ValidityDate | תאריך | ✔ | `dd/mm/yyyy` |
| `אחוז הנחה` | DiscountPercent | אחוז | | |
| `אחוז הנחה קודם` | PreviousDiscountPercent | אחוז | | |
| `מקסימום הנחה` | MaximumDiscount | אחוז | | תקרת אחוז ההנחה |
| `מקסימום שטח` | MaximumArea | מספר עשרוני | | במ"ר |

**כללים**

- הצמד `קוד עירוני` + `קוד חוקי` חייב להתאים לשורה בקובץ הקודים. צמד שאינו קיים
  שם עוצר את הקליטה.
- לאותו קוד אסור שיהיו שתי שורות עם **אותו תאריך**.
- קוד ללא אף שורת תעריף ייקלט, אבל **לא יימצא בשום חישוב** — הקליטה מזהירה על כך.
- תאריכים מתקבלים גם כ-`dd/mm/yyyy`, `yyyy-mm-dd`, `dd.mm.yyyy`, `dd/mm/yy`.

### אחוזים — הנקודה היחידה שמבלבלת

במסד הנתונים אחוז נשמר כשבר: `0.40` = 40%.

- תא **מעוצב כאחוז** (`40%`): נקלט כ-0.40. זו הצורה שהייצוא מייצר.
- תא שמכיל את המספר **40** ללא עיצוב: נקלט כ-0.40, עם אזהרה שאומרת איך הוא הובן.
- מספר גדול מ-100 נדחה כשגיאה.

### דוגמה — קוד שהשתנה באמצע השנה

```
קוד עירוני | קוד חוקי | תאריך תחילת תוקף | אחוז הנחה | מקסימום שטח
570        | 570      | 01/01/2025       | 70%       | 10000
570        | 570      | 01/01/2026       | 70%       | 10000
570        | 570      | 15/03/2026       | 60%       | 10000
```

בקשה מ-10/02/2026 מקבלת 70%, בקשה מ-01/04/2026 מקבלת 60%. החלטה שכבר נרשמה
בפברואר אינה משתנה למפרע — הסכום שחושב נשמר על הבקשה עצמה.

## הרצה משורת הפקודה

```bash
# ייצוא הרשות הנוכחית
python PythonScripts/export_discount_codes.py <codes.xlsx> <rates.xlsx>

# בדיקה בלבד — לא נכתב דבר
python PythonScripts/import_discount_codes.py <codes.xlsx> <rates.xlsx> --dry-run

# קליטה — מוחק את הקודים הקיימים ומחליף
python PythonScripts/import_discount_codes.py <codes.xlsx> <rates.xlsx> --replace
```

הקליטה כולה בטרנזקציה אחת: כישלון באמצע משאיר את המסד כפי שהיה.

## מה קורה בקליטה, לפי הסדר

1. שני הקבצים נקראים ונבדקים במלואם. שגיאה בשורה כלשהי עוצרת הכל לפני כתיבה.
2. `--dry-run` מסתיים כאן ומדפיס מה היה נקלט, כולל היסטוריית השינויים של כל קוד.
3. `--replace` מוחק את `tbDiscountsCodes` — גרסאות התעריף נמחקות איתו דרך
   ה-FK — וטוען את הקודים מחדש, ולכל קוד את שורות התעריף שלו.
4. המסך נטען מחדש והקודים החדשים מוצגים.

הנתונים של התושבים (`tbYearlyDiscounts`, `tbDiscountRequests`) **אינם מושפעים**.
בקשות מקושרות לקוד לפי המספר העירוני, ולכן כדאי שהרשות החדשה תשתמש באותם מספרים.
